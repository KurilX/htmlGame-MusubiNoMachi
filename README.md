# 結ノ町 — Musubi no Machi

一个**单文件、双击即玩**的和风幻想动作 RPG。零依赖、零网络、零外部资源——整个游戏就是一个 0.94 MB 的 `game.html`。

> 目标不是做一个 MMO，而是做一个**有 MMO 世界结构感的、二次元轻风格的、以探索与剧情为支柱的和风动作 RPG**。

---

## 直接玩

下载 [`game.html`](game.html)，双击用浏览器打开。没有安装、没有服务器、没有登录。

### 操作

| 按键 | 动作 |
|---|---|
| `W` `A` `S` `D` | 移动（屏幕相对） |
| 鼠标左键 | 攻击（朝鼠标方向） |
| `1` `2` `3` `4` | 技能 |
| `Shift` / 鼠标右键 | 闪避（0.25s 无敌帧） |
| `E` / `F` | 交互（对话、宝箱、碑文、采集） |
| `I` | 背包 |
| `Esc` | 关闭面板 |

### 已实现

**世界**
- 箱庭地图：結ノ町（城镇）+ 霞ヶ原（野外）
- 地形高度场：坡坎、溪谷下切、盆地；城镇恒平
- 地标：五重塔（远景锚点）、石灯笼群、鸟居、木屋、竹林
- 贴地土路 + InstancedMesh 植被（草丛 420 丛 / 野花 150 朵）
- 昼夜循环：光照、天空、雾随时间变化；夜间刷特定怪

**战斗**
- 动作向：鼠标指向、突进普攻、4 技能、闪避
- 打击反馈四件套：hitstop / 屏震 / 伤害数字 / 受击闪白
- 5 种怪物（鬼火 / 河童 / 幽霊 / 小鬼 / 天狗），3 个独立刷怪区

**成长**
- 等级 1→10、装备（3 部位 × 5 品质 × 1~3 词条）
- 掉落、商店、**词条重铸**（赌博式，刷的动力来源）

**叙事**
- 主线「結」：每修一处结 = 一段被遗忘的记忆
- 4 个 NPC（含昼夜两套位置）、可分支对话、碑文碎片、任务

**系统**
- 3 槽存档 + 自动存 + JSON 导入导出
- 程序化 BGM（都节音阶）+ 18 个合成音效
- 全中文界面

## 技术要点

**单文件交付的硬约束**决定了整套技术选型：

| 决策 | 原因 |
|---|---|
| Three.js r160 UMD 内联 | `file://` 下 ESM 跨文件被 CORS 拦，只能用 classic script |
| 全部贴图程序化生成 | 零图片文件；`12-textures.js` 用 canvas 画木纹/石砖/瓦片/草叶 |
| 无 `fetch` / `XHR` | `file://` 下读本地文件会失败，数据全写成 JS 字面量 |
| 存档走 localStorage + 导出兜底 | `file://` 下 localStorage 可用但不保证 |

**渲染管线**（`11-pixels.js`）

```
场景 → 离屏 RT(1152×648) → Sobel 描边后处理 → 屏幕
```

内部 1152×648 而非 640×360：5.5 头身角色在 640×360 下只有 37px 高、每头 6.7px，五官物理上画不出来。这个取舍的代价是像素味变淡，更接近"高清低模 + 描边"。

**着色**（`10-shaders.js` + `12b-celshade.js`）

- `MeshToonMaterial` + 3 阶阶梯渐变 → 赛璐璐硬边
- 彩色阴影：暗部不是"颜色×系数"（那会发灰），而是 HSL 变换——色相向蓝紫偏、饱和度提升、亮度降低

## 开发

```bash
# 开发入口（多文件，可直接 file:// 打开）
dev.html

# 构建单文件
node build.mjs

# 验收（会自己拉起独立 Chrome，动态申请端口）
node tools/verify-d1.js      # 玩法 20 项
node tools/verify-build.js   # 单文件 21 项
```

### 目录

```
src/
  00-core.js        命名空间、数学、RNG、配色
  10-shaders.js     赛璐璐材质 + 描边后处理
  11-pixels.js      低分辨率渲染管线
  12-textures.js    程序化材质贴图（9 种）
  12b-celshade.js   彩色阴影（HSL 变换注入）
  20-art-chibi.js   角色立绘绘制（8 方向 × 13 帧）
  21-art-world.js   场景物件建模（鸟居/五重塔/樱花/竹林…）
  50-world.js       世界构建与运行时
  51-terrain.js     地形高度场
  40~46            玩家 / 敌人 / 技能 / 战斗 / 特效 / 投射物
  60~61            背包装备 / 任务
  70~72            UI / 对话 / 音频
  80-save.js       3 槽存档
  90-arch.js       世界状态 / 玩家意图分层（为将来联机预留）
  91-main.js       引导与主循环
  data/            纯数据（怪物/物品/技能/地图/对话/任务）
tools/
  cdp.js           CDP 安全封装（动态端口 + 归属校验）
  verify-d1.js     玩法验收
  verify-build.js  单文件验收
docs/
  PLAN.md          设计定稿 + 模块清单 + 数据表结构
  art/             风格参考图
```

### 验收脚本的一条铁律

`tools/cdp.js` 强制**动态申请空闲端口**并做三重归属校验（端口归属 / 目标必须是空白页 / user-data-dir 唯一标记）。绝不硬编码 CDP 端口——曾因写死 9333 撞上本机 Amlcowork 桌面客户端的调试端口，把测试页导航进了正在使用的窗口。
