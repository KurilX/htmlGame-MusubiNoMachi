# 結ノ町 — 项目方案（v0.1 定稿）

> 状态：**设计已对齐，待批准开工**。本文档是施工地基，不是宣传材料。
> 定稿日期：2026-11-11

---

## 0. 一句话定义

> **做一个「有 MMO 世界结构感的、二次元轻风格的、以探索与剧情为支柱的和风动作 RPG」——不是一个 MMO。**

**它是什么**
- 动作向战斗（鼠标指向、突进普攻、4 技能 + 闪避、hitstop / 屏震 / 伤害数字 / 受击闪白）
- 固定箱庭地图（一座城镇 + 一片有纵深的野外）+ 固定位置副本
- 赛璐璐着色的低模 3D 场景 + 2D chibi 纸片人角色（8 方向 billboard）+ 低分辨率渲染 + 描边
- 剧情当承重墙：15~20 分钟主线、3~5 个可对话 NPC、可分支
- 和风幻想 + 高明度粉彩

**它不是什么（这些是被明确否掉的）**
- ❌ 传奇私服味：假玩家影子、滚动假世界频道、世界 BOSS 公告
- ❌ PS1 那种"脏、旧、糊"的像素风（我们的像素感来自低模 + 色阶 + 描边，不是来自低分辨率糊屏）
- ❌ 真联机（v0.1 一行服务器代码都没有）
- ❌ 骨骼动画角色（全部 billboard 立绘）
- ❌ 8 头身写实比例

## 1. 技术底座（全部锁定）

| 项 | 决定 | 理由 / 后果 |
|---|---|---|
| 交付物 | **单文件 `game.html`**，双击 `file://` 打开，零网络零 CDN | 发给任何人都是一个文件 |
| 引擎 | **Three.js r160 UMD**（全局 `THREE`），内联进 HTML | 已实测：unpkg 可取，669,884 B，`REVISION === 160`；jsdelivr 在本机被 TLS 重置，不可依赖 |
| 引擎固化 | `vendor/three.min.js`（构建前一次性 vendor 进仓库） | 构建链从此完全离线，不受 unpkg 抖动影响 |
| 脚本形态 | **全部 classic `<script>`**（无 ESM、无 `import`） | `file://` 下跨文件 module 被 CORS 拦；classic script 同目录加载正常 |
| 开发形态 | `dev.html` 用多个 `<script src="src/*.js">` 按序加载，共享命名空间 `G` | 调试友好，且**在 `file://` 下也能直接跑** |
| 发布形态 | `build.mjs` 按序拼接 → 内联 three + 内联游戏代码 → `game.html` | 无需打包器 |
| 内部渲染分辨率 | **640×360**，nearest 整数倍放大到全屏 | 1080p 上正好 3 倍；480×270 会让 chibi 脸糊成一团 |
| 着色 | **赛璐璐 2~3 阶色阶**（自定义 shader）+ 深色描边（Sobel 后处理） | "二次元感"的真正来源 |
| 贴图 | **程序化生成**（canvas 代码画），无图片文件 | 零外部资源 |
| 角色 | **2D chibi 立绘**，8 方向 × 4 帧走路 + 各动作帧，代码程序化绘制 | 绕开骨骼动画 |
| 音频 | **WebAudio 程序化合成**：1 段循环 BGM（都节调式）+ 6 个音效 | 零音频文件 |
| 存档 | localStorage **3 槽位** + 当前槽自动存 + **JSON 导入/导出** | `file://` 下 localStorage 可用但不保证，导出是唯一可靠迁移手段 |
| UI | **DOM 层叠在 canvas 之上**，不参与像素化 | 字永远清楚 |
| 界面语言 | 中文 | |
| 体积预估 | **1~1.5 MB**（three 670KB + 代码） | 程序化资源让体积远小于最初估的 5~30MB |

### `file://` 约束清单（写代码时必须绕开的坑）
- ❌ 不能用 `fetch` / `XHR` 读本地文件 → 所有数据写成 JS 字面量（`const DATA = {...}`）
- ❌ 不能用 Web Worker（内联 blob worker 可用但不可靠）→ 所有逻辑主线程，注意帧预算
- ❌ 不能用 ES module 跨文件 → 用 classic script + 全局命名空间
- ⚠️ localStorage 在 Chrome/Edge 可用，Safari 可能按会话隔离 → 必须提供导出/导入
- ⚠️ `navigator.clipboard.writeText` 在 `file://` 下常被拒 → 导出走 `<a download>` + `URL.createObjectURL(Blob)`
- ✅ WebGL / WebAudio / PointerLock / canvas 全部正常

## 2. 美术规格

| 项 | 参数 |
|---|---|
| 参考 | Moonlighter 的**构图与配色**（干净大色块、强明暗对比、居中留白），《八方旅人》的**画面骨**（真 3D 场景 + 2D 纸片人） |
| 色阶 | 赛璐璐 2 阶（亮部/暗部）+ 环境光提亮暗部；不用 3 阶以上 |
| 调色板 | 高明度粉彩主导：樱粉 `#F7C8D8`、奶白 `#FBF3E4`、浅空蓝 `#B8DCE8`、苔绿 `#9CB87A`、朱红点缀 `#D9483B`（鸟居/纸灯） |
| 描边 | 后处理 Sobel 边缘检测，1px，颜色不用纯黑而用**深褐 `#3A2E2A`**（纯黑太硬，不"轻"） |
| 角色比例 | **2.5 头身 chibi**，眼睛占脸 1/3（二次元标配），自带描边 |
| 角色绘制 | 代码程序化：椭圆脸 + 大眼 + 2.5 头身 + 顶点色渐变；**先做中性主角一套**，敌人用形状+配色区分 |
| 方向与帧 | 8 方向 × 4 帧走路；待机 2 帧呼吸；攻击 3 帧；受击 1 帧；死亡 3 帧 |
| 光照 | 1 主方向光（带硬阴影）+ 1 环境光；昼夜改方向光颜色与强度，不改结构 |
| 场景元素 | 鸟居（4 柱）、纸灯（发光球 + 描边）、樱花（粒子）、石阶、木屋、竹林、溪谷、藤蔓 |
| 相机 | **等距俯视**：俯角固定 ~35°，可左右绕轴旋转 45° 步进，不可自由俯仰；WASD 屏幕相对移动 |

> **备用方案（重要）**：若程序化 2D 立绘在 D2 闸口达不到"看着舒服"的标准，**降级为低模 3D chibi**（同色块、同描边、同样 2.5 头身）。这会牺牲部分"二次元感"，但保证项目不死。这是唯一的兜底路径，不引入第二套美术方向。

## 3. 世界观与叙事

### 设定
**和风幻想 · 高明度粉彩**。世界靠一条「**結いの綱**（结绳）」维系——它不是实体绳，是万物之间"还记得彼此"这件事本身。绳在某处断了，于是那片土地上的东西开始**从记忆里淡出**：路忘了通向哪，人忘了自己是谁。

### 主角
**半固定**：身份固定——你是「**結び手**（结绳者）的见习」，刚收到一封没有署名的信，被派到結ノ町。可以**换外观与性别、自己起名**，关键节点有 **2~3 个对话选择**，但主线台词是写好的。

### 核心叙事机器（这是本作真正的骨架）
> **每修好一处结 → 一段被刻意遗忘的记忆回到世界。**

这条规则一石三鸟：
- 给了你去每个角落的理由（那里有结）
- 给了碑文/残页存在的理由（被遗忘的记忆碎片）
- 给了副本存在的理由（结断在深处）

### 三个地点
| 地点 | 定位 | 内容 |
|---|---|---|
| **結ノ町**（むすびのまち） | 安全区 / 世界结构感中心 | NPC、商店、任务板、可重铸词条的铁匠、灯（昼夜可见的视觉锚点） |
| **霞ヶ原**（かすみがはら） | 野外，纵深优先 | 打怪、采集、隐藏宝箱、碑文、结（3 处）、副本入口在尽头 |
| **忘れ緒の社**（わすれおのやしろ） | 固定位置副本 | 前厅 + 3 房间 + Boss 房；壁画、别人留下的痕迹、剧情高潮 |

### 剧情规模
- **15~20 分钟主线**，3~5 个可对话 NPC
- 每个 NPC **3~6 句**，含 **2~3 个分支选项**（分支影响台词与一个小奖励，不分裂主线）
- 文本：**我写初稿，你改**
- 剧情节点解锁技能 3、技能 4（见 §4.1）

## 4. 玩法系统

### 4.1 战斗（动作向）
| 项 | 决定 |
|---|---|
| 瞄准 | **鼠标指向**（技能飞向鼠标位置） |
| 普攻 | **短距离突进挥击**，有明显前摇（可被躲） |
| 武器 | **单刀**，无切换。核心演出是**居合**：蓄力 → 瞬移斩 → 收刀 |
| 技能 | **4 个 + 1 闪避**；技能 3、4 靠剧情/等级解锁 |
| 资源 | **纯冷却制**（无蓝无体力） |
| 闪避 | **滾**，0.25s 无敌帧 |
| 打击反馈 | hitstop **60ms** / 屏幕震动 / 浮动伤害数字 / 受击闪白 + 击退（四件套全上） |

**技能表**
| # | 名 | 类型 | 解锁 |
|---|---|---|---|
| 1 | 抜刀・月影 | 直线突进斩（居合演出） | 初始 |
| 2 | 斬鉄・輪 | 自身周围 360° 环形斩 | 初始 |
| 3 | 飛刃・風切り | 投掷气刃，穿透 2 个目标 | 剧情节点 A |
| 4 | 受け流し | 1.5s 内受击则反击 + 击退 | 剧情节点 B |
| — | 滾 | 位移 + 0.25s 无敌 | 初始 |

### 4.2 昼夜
- 游戏内 **1 天 = 20 分钟**；光照颜色/强度渐变，天空色随之时变
- **夜间刷特定怪**（雾系、灯系），白天刷另一批
- NPC 只做 **昼 / 夜两套位置**，不做小时级作息表

### 4.3 死亡与惩罚
- **野外死亡**：回結ノ町复活；**地上未拾取的掉落消失**；背包全保留；**不掉金币**
- 从城镇走回野外单程 **30~45 秒**（有传送点，但非零成本）
- **副本内死亡**：本次副本进度清空，退出副本
- 设计意图：惩罚**战斗失误**，不惩罚**探索**（探索是本作最珍视的东西）

### 4.4 成长与经济
| 项 | 决定 |
|---|---|
| 等级 | 1 → 10，每级 +10% 主属性，升级回满血 |
| 装备位 | **3 个**：武器 / 护符 / 衣装 |
| 品质 | **5 档**：粗物 / 常品 / 良品 / 名品 / 灵宝（颜色区分） |
| 词条 | 每件装备 **1~3 条**，从词缀池按品质抽 |
| 金币来源 | 打怪、卖装备、副本奖励 |
| 商店 | 卖消耗品 + **保底装**（脸黑也能买到能用的定型装备），价格随昼夜轻微浮动 |
| **词条重铸** | 铁匠处花金币**重掷某一件装备的全部词条**（赌博式），品质越高越贵 —— 这是刷的动力来源 |
| 生活副活动 | **极薄版**：采集矿点/草药 3 处 + 钓鱼点 1 处 + 烹饪 4 个配方（做回血/加攻料理） |

### 4.5 探索
1. **隐藏宝箱**：可破坏的罐子/草丛后有东西，野外与副本内散布约 12 处
2. **碑文与残页**：世界观碎片，与「每修一处结就记起一段」互补，约 15 处
3. **NPC 日程带来的人景变化**：昼/夜两套位置，让"再来一次"有意义
4. **结**：3 处主线探索点，触碰即推进剧情并解锁一段记忆

### 4.6 怪物
5 种普通怪 + 1 精英 + 1 Boss（初期估算；若工期紧，普通怪降到 4 种）
| 类型 | 行为 |
|---|---|
| 近战冲锋 | 直线追，贴脸挥击，前摇明确 |
| 远程投射 | 拉开距离投射，被贴身则后退 |
| 群居 | 3~5 只一起，仇恨联动 |
| 肉盾 | 慢、血厚、有格挡姿态 |
| 精英 | 组合技能，带护盾阶段 |
| Boss | 三阶段：近战连斩 → 召唤 → 全屏前摇 AOE |

## 5. 数据表结构（全部 JS 字面量，`src/data/`）

> 数值全部数据驱动：你改数值不用碰一行逻辑。

```js
// 怪物
Monsters: { id, nameZh, nameJa, tier: normal|elite|boss, level,
  hp, atk, def, moveSpeed, aggroRange, attackRange, attackCd,
  telegraphSec,            // 前摇秒数
  ai: { type: chaser|ranged|pack|tank|boss, params:{} },
  skills: [skillId],
  lootTableId, expReward, goldMin, goldMax,
  flags: { nocturnal, group, flying } }

// 掉落表
LootTables: { id, entries: [{ itemId, weight, qtyMin, qtyMax, qualityFloor }],
  guaranteed: [itemId], goldWeight }

// 装备
Items: { id, name, slot: weapon|charm|robe, quality: 1..5,
  baseAtk, baseDef, affixSlots: 1..3, affixPoolId,
  iconSeed,               // 程序化图标种子
  value, lore }

// 词缀
Affixes: { id, name, stat: atk|hp|crit|speed|lifesteal|...,
  min, max, weight, qualityMin }

// 技能
Skills: { id, name, type: dash_arc|aoe_ring|projectile|parry|dodge,
  cooldown, damageMult, range, angle, castTime, telegraphSec,
  hitstopMs, shakeAmp, vfxSeed, sfxId, unlock: { type, value } }

// NPC
NPCs: { id, name, spawnDay: {x,z}, spawnNight: {x,z},
  dialogueId, shopId, quests: [questId] }

// 对话
Dialogues: { id, speaker, lines: [string],
  choices: [{ text, next, effect }], condition }

// 任务
Quests: { id, title, giverId, brief,
  steps: [{ type: kill|collect|talk|reach, target, count }],
  rewards: { exp, gold, items:[] }, nextId }

// 区域
Zones: { id, name, bounds, spawnTables: { day, night },
  interactables: [uid], portals: [{ toZone, at, requirements }] }

// 可交互物
Interactables: { uid, type: chest|stele|knot|node, pos,
  contents, textId, onceOnly, requiresQuest }

// 商店
Shops: { id, stock: [{ itemId, qty }], restockRule, priceJitter }

// 重铸
Reforge: { costByQuality: [..], affixRerollPoolId }

// 存档
Save: { version, slot, createdAt, playedSec,
  player: { name, appearance, level, exp, hp, gold,
            equip:{weapon,charm,robe}, bag:[], position:{x,z}, zoneId },
  world: { flags:[], timeOfDay, opened:[], killed:[], knots:[] },
  stats: { kills, deaths, drops } }
```

## 7. 三道闸（中间态验收）

| 闸 | 何时 | 交付什么 | 你要看什么 |
|---|---|---|---|
| **D1** | 单位 7 后 | `game.html` 可玩灰盒：**方块替身**、1 块空地、3 种怪、普攻 + 2 技能 + 闪避 | **手感对不对味**。不对现在改，代价 1 单位；D3 才发现，代价 5 单位 |
| **D2** | 单位 14 后 | 真 chibi 立绘 + 赛璐璐 + 描边 + 結ノ町 + 霞ヶ原外观 | **好不好看、像不像二次元**。这是立绘兜底方案（降级低模 3D）的决策点 |
| **D3** | 单位 19 后 | 全部系统跑通：主线 / 副本 / 装备 / 重铸 / 存档 / 昼夜 / 音频 | **完整一轮能不能玩 20 分钟不烦**，剩下 2 单位去毛刺 |

**最终验收标准（唯一一条）**：玩 10 分钟后，你自己想再玩 5 分钟。

**交付验证方式（我这边执行）**：用 Playwright 的 chromium 以 `file://` 真实打开 `game.html` 并截图确认渲染、点击、按键，不只看"生成成功"。

```
      ├─ monsters.js  ├─ items.js   ├─ affixes.js  ├─ skills.js
      ├─ npcs.js      ├─ dialogue.js ├─ quests.js  ├─ zones.js
      └─ shops.js
```

**架构预留（`90-arch.js`）**：所有世界变更都走 `dispatch(intent)` → `reduce(state, intent)`，渲染只读 state。v0.1 里 `dispatch` 是同步本地调用；将来接 WebSocket 只需把 dispatch 换成"发到服务端 + 等权威 state 回包"，游戏逻辑一行不用改。**这是 Q2 选 A（只留架构）的全部落地方式，不额外增加工时。**

## 10. 风险清单

| 风险 | 影响 | 缓解 |
|---|---|---|
| **程序化 chibi 立绘做不好看** | 高——直接砸掉"二次元"这个立身点 | D2 闸口是决策点；兜底降级低模 3D chibi（同色块同描边） |

| 低分辨率 + 描边后处理有摩尔纹 | 中 | 描边阈值可调；实在不行改几何描边（反向外壳） |

| 20 分钟昼夜与探索节奏冲突（走到一半天黑了） | 低 | 昼夜时长写进配置，可一键改 10/20/40 分钟 |
